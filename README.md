# Baumrecht — klickbarer Prototyp

Statische Demo für BimParts: Location-Packs (Zürich, Wien, München, Berlin, Musterhausen), simuliertes Update, Freigabe, Versionen.

**Keine Live-Abfrage** von Amtsseiten, kein API-Key, nichts zu installieren.

Öffnen: GitHub Pages-URL dieses Repos.

## Ablauf zum Kommentieren

1. Orte durchklicken, JSON-Pack laden.
2. **Demo-Verordnung** → «Beispiel-Novelle einspielen» (ändert 4 Zahlen) oder selbst editieren.
3. **Aktualisieren** — Fortschritt ist simuliert, Diff ist echt (Text vs. genehmigte Fassung).
4. **Prüfen** → Freigeben → **Versionen**.

Feedback: was fehlt für REGISA / BimTree, welche Parameter, welche UI.
